# Basic_ATM_Managment (Java OOP Project)
## 📌 Description

This is a simple **ATM Management System** written in Java using Object-Oriented Programming (OOP) principles. The application simulates basic ATM operations like login authentication, checking and savings account management, viewing balances, making deposits, and withdrawals.

## 🚀 Features

- User authentication with Customer Number and PIN.
- Access to Checking and Saving accounts.
- Balance inquiry for each account.
- Deposit and Withdrawal functionality.
- Console-based menu navigation.
- Simple data management using `HashMap`.

## 🛠 Technologies Used

- **Java** (JDK 8 or later)
- **OOP Concepts**: Inheritance, Encapsulation
- **Collections API**: `HashMap`
- **Console I/O**: `Scanner`
- **Formatting**: `DecimalFormat`
